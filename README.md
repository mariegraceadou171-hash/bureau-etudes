# Bureau d'études

Projet 1 : programme Python en console pour le prédimensionnement
des poteaux et des semelles.

## Installation

```
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## Lancer le programme

```
python src/main.py
```

## Structure du projet

- `src/` : le code (prédimensionnement, menu, et modules à compléter)
- `donnees/` : les fichiers de données
- `tests/` : les tests

## Tests

```
python tests/test_predimensionnement.py
```
